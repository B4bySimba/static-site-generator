# About this site

This blog is generated by a static site generator built from scratch - no Eleventy, no
Hugo, no Astro. The Markdown parser is a **vendored copy** of another project in the same
portfolio, and the template engine, asset pipeline, and feed generators are all hand-written.

The point is not that you should use it. The point is that after building one, you know
exactly what the ones you *do* use are doing.
